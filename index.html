關於上通・下通

上通（かみとおり）與下通（しもとおり）是熊本市中心最熱鬧的兩條購物街，這裡匯集了傳統美食與現代餐飲，是品味熊本道地料理的最佳地點。

從熊本車站搭乘市電約15分鐘即可抵達，無論是馬肉料理、熊本拉麵，還是精緻甜點，這裡都能滿足您的味蕾。

✈️ 機場/航空禁帶物品一覽

以下規則為通用標準，實際規定請依航空/機場公告為準

🎒

隨身 vs 托運

✓ 可隨身

手機、平板、手錶、眼鏡、書籍、衣物、個人化妝品（固體）

🚫 禁隨身

刀具、剪刀、液體（100ml以上）、膠水等易燃物

✓ 可托運

大部分液體、固體化妝品、衣物、電子產品

💧

液體 100ml 規則

規則

單件液體容器 ≤ 100ml，總量 ≤ 1L（1公升），放入透明夾鍊袋

液體定義

乳液、喜歡、化妝水、香水、牙膏、洗面乳、沐浴乳等

提示

備用組件需放托運；部分機場可購買安檢後液體

🔋

行動電源/鋰電池

✓ 可隨身

額定能量 ≤ 100Wh（20,000 mAh），最多 2 件

🚫 禁隨身

額定能量 > 160Wh；未安裝之單獨電池

注意

同時隨身攜帶不超過 2 件；超容量需托運或不攜帶

✂️

刀剪尖銳物

🚫 全面禁止

刀具（含美工刀）、剪刀、指甲剪、尖頭工具、剃鬚刀

✓ 例外

托運行李可攜帶鈍刀（需包裝安全，刃長 ≤ 15cm）

提示

抵達目的地後可購買；指甲剪在日本便利店有售

🔥

易燃/噴霧產品

🚫 禁止

汽油、酒精、香蕉水、膠水、殺蟲劑、防曬噴霧

特殊規定

除臭噴霧、髮膠可托運（有限制），但隨身完全禁止

替代方案

到日本後購買當地產品；防曬液（非噴霧）可隨身

🔦

打火機/火柴

🚫 全面禁止

所有類型打火機（含香煙打火機）、火柴完全禁止

隨身+托運

兩者都禁止；無特殊例外

替代方案

到日本後購買；7-11 便利店有售

⚙️

壓縮氣體/其他危險品

🚫 禁止

瓦斯罐、氧氣瓶、乾冰、爆竹、磁鐵（超規格）、放射性物質

常見易忽略

乾冰、磁性玩具、某些醫療設備可能有限制

建議

如有特殊物品，提前聯繫航空公司確認

✈️ 機場安檢小貼士

  • 提前到達：國際班機建議起飛前 3 小時到達機場，預留安檢時間
  • 液體分裝：帶著透明夾鍊袋過安檢，100ml 以下單件液體無需分裝
  • 電子產品：筆記型電腦、平板需從包包取出過 X 光機
  • 腰帶/鑰匙：金屬物品提前取下，放入包包或托盤
  • 鞋子：取下鞋子放入安檢托盤（某些機場可保留）
  • 海關申報：攜帶超過美金 $10,000 等值現金需申報
  • 購物後液體：安檢後購買的液體可隨身帶上飛機
  • 如有疑問：直接詢問安檢人員，不確定的物品事先提出

行前小提醒

🕒

營業時間

大部分店家午餐 11:30-14:00，晚餐 17:30-22:00。建議提前確認，部分店家週一或不定期公休。

👥

排隊文化

熱門店家用餐時段常需排隊 30-60 分鐘，建議避開尖峰時段（12:00-13:00、18:30-20:00）或提前訂位。

💳

支付方式

多數店家接受現金，部分支援 IC 卡（SUICA、PASMO）或信用卡。建議隨身攜帶現金以備不時之需。

🗺️

交通資訊

搭乘熊本市電至「通町筋」站下車，步行即達上通・下通商圈。兩條街相距約 5 分鐘步行距離。
